# Python Mini Projects 🐍

A collection of small Python projects built for practice and learning — covering basics like logic building, file handling, GUIs, and simple games.

Each project lives in its own folder with its own code and a short README explaining what it does and how to run it.

## 📂 Projects

| Project | Description |
|---|---|
| [Password Generator](./password-generator) | Generates random, secure passwords based on user-defined length and character rules |
| [Snake Game](./snake-game) | Classic Snake game built using Python (Pygame/Turtle) |

## 🚀 How to Run

Each project is self-contained. To run any project:

```bash
git clone https://github.com/thabhikushwaha/python-projects.git
cd python-mini-projects/<project-folder>
python main.py
```

Some projects may need extra libraries — check that project's own README for setup steps.

## 🛠️ Tech Stack

- Python 3.x
- Standard library (some projects may use extra packages like `pygame`, listed in that project's own folder)

## 📌 Purpose

This repo is meant to track my progress while learning Python — small, focused projects rather than one big application. Bigger/serious projects live in their own separate repos.
